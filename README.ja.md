## Windowsでのインストール

1. `Klakk-1.4.4-Windows-Setup.exe`をダウンロードします。1つのインストーラーがARM64またはx64を自動で選び、必要なランタイムも含みます。
2. 現在のWindowsインストーラーは**未署名**です。Windowsの警告が表示された場合は、配布元を信頼できるか確認してから実行を判断してください。チェックサムはファイルの一致を確認するもので、発行者の署名の代わりにはなりません。
3. インストーラーを実行します。最後の画面に **Launch Klakk** が表示されたら、チェックを入れたまま **Finish** をクリックします。起動しなかった場合は、Windows のスタート メニューから **Klakk** を開きます。「一般」で「Klakkを有効にする」をオンにし、「オーディオ」で音源、音量、「出力デバイス」を選びます。「システムデフォルト」はWindowsの既定の出力を使います。
4. 物理キーボードを使ってメモ帳に短い文を入力します。音が出ない場合は、Windows の音量ミキサーと試用・ライセンス状態を確認し、下のセットアップガイドを参照してください。

[Windows版のセットアップガイド](https://tryklakk.com/ja/blog/windows-keyboard-sounds-arm64-x64-setup/?utm_source=github&utm_medium=referral&utm_campaign=official_downloads)

購入の続行に更新が必要な場合、Klakk 1.4.4に表示される更新用ダウンロードのボタンから、公式Windowsページに進めます。既存のPancake・Creemライセンスは引き続き利用できます。

Windows版のKlakk 1.4.3を手動でインストールした場合は、Klakkを終了し、1.4.4のインストーラーで既存のインストール先に上書きします。Scoopでインストールした場合は、Klakkを終了して[Scoopの更新手順](packaging/scoop/README.ja.md#更新削除)に従ってください。

WinGet をお使いの方は、次のコマンドで Klakk を新規インストールできます。WinGet のコミュニティ ソースでは、上記と同じ未署名の Windows インストーラーを使用します。

```powershell
winget install --id Klakk.Klakk --exact --source winget
```

WinGet でのインストールが完了したら、試すときに Windows のスタート メニューから **Klakk** を開き、[最初の打鍵音を鳴らす手順](https://tryklakk.com/ja/blog/windows-keyboard-sounds-arm64-x64-setup/#%E6%9C%80%E5%88%9D%E3%81%AE%E6%89%93%E9%8D%B5%E9%9F%B3%E3%82%92%E9%B3%B4%E3%82%89%E3%81%99)に進んでください。

Scoopをすでに利用している場合は、[Klakk開発者が管理するWindowsバケット](packaging/scoop/README.ja.md)から、1.4.4の共通インストーラーで同版を導入できます。[1.4.4 のパッケージ検証](https://github.com/levindong2026/klakk-downloads/actions/runs/45019558379)はネイティブ x64・ARM64 の両方で通過しました。Scoopのmain・Extras公式カタログへの収録とは別の独自配布元です。

## Macでのインストール

1. [公式サイトからMac用DMGをダウンロード](https://tryklakk.com/download/klakk.dmg)し、`Klakk-1.4.4-26.dmg`を開きます。
2. Klakkを「アプリケーション」にドラッグし、そこにコピーしたアプリを開きます。
3. Klakkの案内に従い、「システム設定 → プライバシーとセキュリティ → 入力監視」でKlakkを許可します。macOSが求めた場合はアプリを終了して開き直します。
4. メニューバーのKlakkアイコンをクリックし、「Klakkを有効にする」がオンか確認します。「設定...」から「オーディオ」を開き、サウンドパックを選んで音量を調整し、普段使うアプリで入力します。

初回起動時の案内で **Later** を選び、まだ入力監視を許可していない場合は、メニューバーの Klakk アイコンから **⚠️ Grant Input Monitoring Permission** を選びます。案内が表示されたら **Open Settings** を押し、「入力監視」で Klakk を許可します。macOS に求められた場合は、Klakk を終了して開き直してください。

現在のDMGにはKlakk 1.4.4（ビルド 26）が入っています。アプリとDMGはDeveloper IDで署名され、Appleの公証を受けています。入力監視は、ほかのアプリでのキー入力に合わせて音を再生するために使います。権限を許可する前に[Mac版のプライバシーポリシー](https://tryklakk.com/ja/privacy/)をご確認ください。

[Mac版のインストールガイド](https://tryklakk.com/ja/blog/mac-direct-download-install-guide/?utm_source=github&utm_medium=referral&utm_campaign=official_downloads)

すでに Homebrew を利用している場合は、[Klakk 開発者の tap](https://github.com/levindong2026/homebrew-klakk)から Mac 公式サイト版を導入できます。[現行 1.4.4（ビルド 26）の検証](https://github.com/levindong2026/homebrew-klakk/actions/runs/45142049391)では、GitHub の Apple シリコン（macOS 26）と Intel（macOS 15）の両環境で、新規インストールとアンインストールを確認しました。アプリの起動は検証の範囲外です。[Homebrew の Mac 動作環境](https://docs.brew.sh/Installation#macos-requirements)では、現在 Apple シリコン搭載の macOS 15 以降がサポート対象です。Klakk が動作する Mac のうち、macOS 14 や Intel Mac は Homebrew の [Tier 3](https://docs.brew.sh/Support-Tiers#tier-3) に当たります。Homebrew が使えない場合は、[公式 DMG](https://tryklakk.com/download/klakk.dmg)を利用できます。[旧版 1.4.3（ビルド 25）](https://github.com/levindong2026/homebrew-klakk/actions/runs/45024474779)と[旧版 1.4.2](https://github.com/levindong2026/homebrew-klakk/actions/runs/42089541789)の検証記録も参照できます。この tap は開発者が管理しており、Homebrew の公式 cask カタログとは別です。

### Windows：PowerShellで確認

保存先のフォルダーでPowerShellを開き、次のコマンドを使います。どちらもファイルを読み取るだけで、インストーラーは実行しません。

```powershell
(Get-Item -LiteralPath '.\Klakk-1.4.4-Windows-Setup.exe').Length
Get-FileHash -LiteralPath '.\Klakk-1.4.4-Windows-Setup.exe' -Algorithm SHA256 | Format-List Algorithm,Hash
```

1行目にバイト数、2行目にアルゴリズムとSHA-256の全桁が表示されます。ブラウザがファイル名を変更した場合は、2 か所のファイル名を実際に保存した名前に置き換え、表の該当行と比べてください。ファイル名を変えても、内容が同じならハッシュ値は変わりません。

### Mac：ターミナルで確認

DMG を保存したフォルダーで実行します。旧版のMac用DMGやZIPを確認する場合は、保存したファイル名に置き換え、旧版の表の該当行と比べてください。

```sh
stat -f '%z' 'Klakk-1.4.4-26.dmg'
shasum -a 256 'Klakk-1.4.4-26.dmg'
```

1行目にバイト数、2行目にSHA-256とファイル名が表示されます。ハッシュの英字は大文字・小文字を区別せず、全桁を照合します。バイト数またはSHA-256が一致しないときは、開く前に選んだ版とファイル名を確認し、[Windows 1.4.4](https://github.com/levindong2026/klakk-downloads/releases/tag/v1.4.4)または[Macの公式ダウンロード](https://tryklakk.com/download/klakk.dmg)で該当するファイルを取り直してください。旧版は配布記録を確認してください。チェックサムの一致は、開発者署名の代わりにはなりません。現在のWindowsインストーラーは未署名です。
