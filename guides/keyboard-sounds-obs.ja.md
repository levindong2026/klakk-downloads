# OBSにキーボード音が入らないとき：再生・音声取り込み・録音トラック

[English](keyboard-sounds-obs.md)

まずキーボード音アプリが音を出しているか、次にOBSがその音を受け取っているか、最後に保存した動画の音声トラックに入っているかを確認します。

2026年10月11日更新。Klakk開発者のLevinが管理し、文章作成にはAIを補助的に使用しています。OBSの手順はリンク先の公式資料に基づきます。すべてのアプリや機器での録音を実機検証した結果ではありません。

## 1. 音が止まる段階を分ける

同じヘッドホンまたはスピーカーで、メモ帳・テキストエディットなどの通常の編集アプリと、問題が起きるOBS内の入力欄に短い文章を入力します。音声取り込みの設定を変える前に、アプリの再生音を聴いてください。

| 確認できた状態 | 次に調べること |
| --- | --- |
| どちらの入力場所でも音が出ない | アプリの有効化、音量、出力先、権限、試用・ライセンス状態を確認します。Klakkの手順は[最初の音が出ないときの確認](klakk-no-sound.ja.md)にあります。 |
| 編集アプリでは鳴るが、OBS内の入力時だけ止まる | OS・OBS・音アプリのバージョンと、入力中のウィンドウを記録します。まず入力の検知と再生を調べます。取り込み設定だけでは原因を特定できません。 |
| 手元では聴こえるが、その音を取り込むOBSソースのメーターが動かない | 対象のアプリや出力先、ソースのミュート・音量・経路を確認します。下のOS別の手順を参照してください。 |
| 対象ソースのメーターは動くが、保存した動画で聴こえない | ソースのミュート、録音トラックへの割り当て、出力で有効なトラック、再生ソフトで選んだトラックを確認します。 |

[2024年6月のOBSフォーラムの報告](https://obsproject.com/forum/threads/mechvibes-sounds-not-working-in-obs.175886/)では、Mechvibesが他のアプリでは鳴り、OBS内の入力時には鳴らないと説明されています。現在見える投稿に原因や解決策の確定はありません。同じスレッドの追加投稿は別の独立した調査ではなく、Klakkに替えれば直るという根拠にもなりません。

## 2. OSに合った取り込みソースを確認する

### Windows

[OBS公式のApplication Audio Captureガイド](https://obsproject.com/kb/application-audio-capture-guide)では、OBS 28以降で、Windows 10のバージョン2004以降またはWindows 11のアプリ別音声取り込みを説明しています。OBS 30.1以降はWindow Capture・Game Captureにも音声取り込み機能があります。

音を出すアプリを対象に選びます。アプリ別のソースと全体のDesktop Audioで同じ音を二重に取り込むと、重複やエコーの原因になります。OBSはアプリ別取り込みを使う場合、全体のDesktop Audioを無効にするよう案内しています。アプリによって対応できない音声出力もあるため、対象ソースのメーターと保存動画を確認してください。これはKlakk固有の取り込み互換性を証明するものではありません。

### Mac

[OBS公式のmacOS音声ガイド](https://obsproject.com/kb/macos-desktop-audio-capture-guide)では、macOS 13以降・OBS 30以降のmacOS Audio Captureを説明しています。デスクトップ全体または指定したアプリの音声を選べます。macOS Screen Captureも音声を取り込めるので、映像用のソースに入る音も確認します。

音アプリで選んだ再生先とOBSの取り込み対象を別々に確認します。ヘッドホンで聴こえることだけでは、録音に入るか、除外されるかは分かりません。ここに示すOBS機能の条件と、下のKlakkの動作環境は別です。

## 3. 保存動画の音声トラックを確認する

OBSのAudio MixerからAdvanced Audio Propertiesを開き、対象ソースをどの録音トラックに割り当てたか確認します。Settings → Outputでは、そのトラックを録音対象として有効にします。続いて、保存動画を開いたプレーヤーや編集ソフトで、聴きたいトラックを選びます。

[OBS公式の複数音声トラックの説明](https://obsproject.com/kb/multiple-audio-track-recording-guide)によると、一般的な動画プレーヤーは一度に一つのトラックを再生します。音が別トラックに保存されていると、通常の再生では欠けているように聴こえます。共有用のミックスに入れる音と、編集用に分ける音を決めてから割り当ててください。

## 4. 短い動画を保存して確かめる

実際に使うシーン、入力場所、出力機器で短く録画し、保存した動画の必要な音声トラックを再生します。一度に一つの設定を変えると、変化した段階を確認しやすくなります。

キーボード音を録音から外したい場合は、パソコン内部の音声取り込みと、マイクが拾う音を分けて確認します。ヘッドホンはスピーカーの音がマイクに入る経路を減らせますが、アプリ音声やデスクトップ音声は直接取り込まれることがあります。Klakkは物理キーボードを静かにしたり、OBSの音声を自動で分離したりするアプリではありません。

解決しない場合は、OS、OBSと音アプリのバージョン、入力したウィンドウ、再生先、取り込みソースの種類、上のどこで音が止まったかを記録してください。「動画に音がない」だけよりも、調べる範囲を絞れます。
